📌 Plantilla para agregar el lado B

Ejemplo con Usuario ⇄ Pedido. El lado A (en Pedido) ya existe; solo falta esto en Usuario:

// ── En Usuario.java (lado B / inverso) ──
@OneToMany(mappedBy = "usuario")          // "usuario" = nombre del campo @ManyToOne en Pedido
@JsonManagedReference("usuario_pedido")   // debe coincidir con el @JsonBackReference del lado A
private List<Pedido> pedidos = new ArrayList<>();

// ...y sus getter/setter

// ── Recuerda (lado A, ya hecho en Pedido.java) ──
@ManyToOne(fetch = FetchType.LAZY, optional = false)
@JoinColumn(name = "usuario_id")
@JsonBackReference("usuario_pedido")
private Usuario usuario;

🔑 Reglas de oro: 1) el mappedBy apunta al nombre del atributo Java del lado A (no a la columna). 2) el @JoinColumn va SOLO en el lado A. 3) usa el mismo string en @JsonManagedReference (lado B) y @JsonBackReference (lado A) para evitar recursión infinita al serializar JSON.
